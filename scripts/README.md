# Reproducing the mathematical illustrations

The SVG figures added to the lecture notes for Weeks 1–9 are generated by the scripts in this directory. They use explicit geometry, mathematical formulas, deterministic synthetic arrays, and seeded numerical experiments. The scripts require Node.js 18 or later and no third-party packages.

Run these commands from the repository root:

```sh
node scripts/generate-figures-part1.mjs
node scripts/generate-figures-part2a.mjs
node scripts/generate-figures-part2b.mjs
node scripts/generate-figures-part3.mjs
```

The scripts overwrite only their own generated SVG files in `media/`. They do not modify lecture notes, source evidence, or other media. Review the Git diff after regeneration.

The scripts cover Weeks 1–3, Week 4, Weeks 5–7, and Weeks 8–9, respectively. Raster simulations use synthetic arrays only; the displayed results and error measurements are instructional examples, not measured forensic or privacy performance. Floating-point results may vary slightly across JavaScript engines.

The existing standalone SVGs for Weeks 10–11 are outside the scope of these generators.
