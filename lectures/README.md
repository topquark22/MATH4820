# Lecture Notes

This directory holds the lecture notes and plans for MATH 4820 / CS 6820. Files are named `weekNN-dayM.md`.

## Scheduling assumptions

- **Lectures:** Two 90-minute lectures per week (Day 1 and Day 2), i.e. 3 contact hours of lecture.
- **Tutorials:** Two 60-minute tutorial sessions per week, taught by a teaching assistant (TA). Tutorials support the lectures (worked problems, lab help).

Both are assumptions. Actual lecture/tutorial length and frequency vary by institution and scheduling; adjust the plans accordingly. Note that `syllabus/course-overview.md` lists "3 lecture hours and 1 lab hour per week" (confirm locally), which does not exactly match this assumption.
