# MATH 4820 / CS 6820 — Workbook

This companion workbook provides mathematical exercises, computational problems, and discussion questions for the lecture material. It is distinct from the laboratory curriculum and formal assessments, and may eventually be developed into a standalone companion to the course text.

## How to Use the Workbook

- Attempt the derivations and proofs independently before consulting the answer sketches.
- State domains, units, mathematical assumptions, numerical conventions, and boundary conditions where relevant.
- For computational exercises, use synthetic or appropriately consented data, document software versions and parameters, and retain independent ground truth for evaluation rather than tuning.
- Report numerical results and limitations, not only attractive visual outputs. Computational exercises are practice problems; formal submission requirements are in the laboratory specifications.
- The existing exercises in the lecture notes remain available as supplementary practice. The weekly workbook files are the primary location for developing further companion exercises.
